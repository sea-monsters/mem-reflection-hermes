# v1.3 — Memory Curator Enhancements

> **Status:** Planned
> **Priority:** P0 → P1 → P2
> **Depends on:** v1.2-beta2 (restructured core/memory/reflection/runtime/web packages)

## Overview

Extend the memory curator from a 4-phase detection-only pipeline to a full 6-phase lifecycle management system with automated dedup/merge, graph edge maintenance, supersedes chain compaction, and cold-store restore graph integration.

## Design Principles (inherited from v1.2)

- **Pure rule-driven**: No LLM calls in the hot path. All decisions based on token overlap, timestamps, config thresholds.
- **Fail-open**: All curator phases wrapped in try/except. Failures logged, never block session lifecycle.
- **Reversible**: All deletions go through cold storage first. Recovery is possible via cold-store restore.
- **Configurable**: Every threshold has a config key under `curator.*` in plugin config.

## Pipeline (6 phases, in order)

```
Phase 1: Similarity Merge        ← NEW — merges near-duplicate memories
Phase 2: Supersedes Compaction   ← NEW — compresses long supersedes chains
Phase 3: Staleness Detection     ← existing
Phase 4: Expired Archive         ← existing
Phase 5: Orphan Edge Cleanup     ← NEW — removes stale graph edges
Phase 6: Report                  ← extended

_restore_from_cold → graph.ensure_meta()  ← NEW
```

## Phase 1: Similarity Merge

### Logic

1. `scan_for_similar()` runs BM25 token-overlap detection (existing)
2. For each pair with overlap ≥ `curator.similarity.merge_threshold` (default 0.7):
   - Skip if either memory already has a supersedes chain (already merged)
   - Skip if bodies are identical (exact dedup — cold-archive one, keep one)
   - Select "keeper" = longer body, "archived" = shorter body
   - Merge: keeper body = keeper.body + `\n---\n` + archived.body (after dedup)
   - Merge: keeper tags = set union of both
   - Archive: set archived.supersedes = [keeper.id], move to cold storage
   - Update keeper via `mem_store.update()`

### Config

```yaml
curator:
  similarity:
    merge_threshold: 0.7    # overlap ratio to trigger merge
    exact_dedup: true        # archive exact duplicates
```

### Edge Cases

| Case | Behavior |
|------|----------|
| Exact duplicates | Archive one, keep one (deterministic: same body → keep first alphabetically) |
| Already-superseded memory | Skip — already part of a merge chain |
| Chain merge (A≈B and B≈C) | Process sequentially: first A+B → C matches merged A, then C supersedes B's successor |
| Pinned memory | Never archived during merge |
| Merge failure (write error) | Fail-open: log warning, skip pair, proceed to next |

## Phase 2: Supersedes Chain Compaction

### Logic

1. Walk each supersedes chain from any node via `store.latest_for()` → chain head
2. Walk chain head backward via supersedes references → collect all nodes
3. If chain length >= 3 (active nodes):
   - Intermediate nodes (not the oldest, not the newest) → cold storage
   - Newest node's `supersedes` → `[oldest_id]` (skip intermediate)
   - Cold storage entry carries full `supersedes_chain: [v1, v2, v3, v4]` for audit

### Config

```yaml
curator:
  supersedes:
    compact_min_chain: 3      # minimum chain length to trigger compaction
    protect_days: 7           # skip chain if any node accessed within N days
```

### Example

```
Before: v1 ← v2 ← v3 ← v4 ← v5  (5 active nodes)
After:  v1 ← v5                   (2 active, v2-v4 in cold with chain evidence)
```

## Phase 5: Orphan Edge Cleanup

### Path A — Immediate (on memory delete)

In `core/store.py::delete()`, after existing SQL cleanup:

```python
conn.execute("DELETE FROM edges WHERE source_id=? OR target_id=?", (mem_id, mem_id))
conn.execute("DELETE FROM graph_meta WHERE memory_id=?", (mem_id,))
```

### Path B — Periodic (curator Phase 5)

```sql
-- Find edges pointing to non-existent memories
SELECT e.source_id, e.target_id FROM edges e
LEFT JOIN memories m ON e.source_id = m.id
WHERE m.id IS NULL
UNION
SELECT e.source_id, e.target_id FROM edges e
LEFT JOIN memories m ON e.target_id = m.id
WHERE m.id IS NULL
```

Then delete all orphan edges found. Runs once per session_end.
